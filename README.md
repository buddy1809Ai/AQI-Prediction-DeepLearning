# Air Quality Index Prediction Using Deep Learning

This project predicts Air Quality Index (AQI) using Deep Learning (ANN).

## Technologies Used

* Python
* TensorFlow
* Streamlit
* Scikit-learn
* Pandas

## Features

* AQI Prediction
* Interactive UI
* AQI Meter
* Pollution Visualization
* Health Recommendations

## Model

Artificial Neural Network (ANN)

## Dataset

India Air Quality Dataset

## Run Project

```bash
pip install pandas numpy scikit-learn tensorflow streamlit plotly joblib
```

```bash
python train_model.py
```

```bash
streamlit run app.py
```
